# Memoria de proyecto

Este directorio conserva contexto útil entre iteraciones. Las notas deben ser breves, fechadas y accionables; no reemplazan el código ni `AGENTS.md`.

```text
progress/
├── explorations/  # documentación, versiones y alternativas investigadas
├── decisions/     # decisiones de arquitectura y producto
├── bugs/          # bugs reproducibles y sus correcciones
├── patterns/      # patrones reutilizables que ya funcionan
└── runs/          # brief, plan, cambios y validación por iteración
```

Antes de una tarea, leer el último run relevante. Después de una tarea, registrar cambios de criterio, bugs no obvios y nuevos patrones. Las fuentes de APIs externas deben ser documentación oficial.
