# Navegación compartida y compacta

## Decisión

La navegación principal usa un único componente segmentado compartido entre
desktop y mobile. Siempre se ubica como una barra flotante inferior, centrada y
con un ancho máximo para conservar una lectura compacta y el acceso con una
mano en cualquier tamaño de pantalla.

Cada opción muestra el icono arriba y el texto centrado debajo. El componente
usa un borde de línea suave, una sombra de elevación en varias capas, fondo
semitransparente y blur para reforzar visualmente que la barra está separada
del contenido sin competir con las tarjetas.

El contenido principal reserva espacio inferior constante para que la barra no
oculte tarjetas ni controles. Se mantienen targets táctiles cómodos, estados
activos accesibles y una sola fuente de verdad para los enlaces de navegación.
