# Exploración inicial del stack · 2026-10-13

Se verificaron las APIs y versiones al crear el proyecto. El lockfile fija React 19.3.0, TanStack React Router 1.170.44, router plugin 1.168.45, Tailwind CSS 4.3.3, Vite 8.3.4, Zustand 5.0.15 y Vitest 5.0.4. TypeScript quedó en 6.0.3 y el lockfile es la fuente exacta de resolución.

Fuentes consultadas:

- [React versions](https://react.dev/versions) y [React Compiler](https://react.dev/learn/react-compiler).
- [TanStack Router con Vite](https://tanstack.com/router/latest/docs/installation/with-vite).
- [TanStack Router file-based routing](https://tanstack.com/router/latest/docs/framework/react/guide/file-based-routing).
- [Tailwind con Vite](https://tailwindcss.com/docs/installation/using-vite) y [configuración CSS-first](https://tailwindcss.com/docs/theme).

La plantilla `react-compiler-ts` ya incluye la integración Babel del Compiler. El plugin de TanStack Router quedó antes del plugin de React para generar `routeTree.gen.ts`.
